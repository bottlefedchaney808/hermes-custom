# Portable CARL command loader

Read the complete CARL skill from the first existing path below:

1. `.claude/skills/carl/SKILL.md`
2. `~/.claude/skills/carl/SKILL.md`

Then execute that protocol using the user’s arguments:

```text
$ARGUMENTS
```

Do not substitute a summary for reading the skill. Preserve these load-bearing requirements: sequential rounds, independent fresh context, independent verification of every finding, `INFRA_BLOCKED` for inaccessible artifacts, and no more than four automatic rounds.
